# Correção NameError de perf_counter — Intranet v2.0.5.3

Erro: NameError: name 'perf_counter' is not defined, Intranet.py linha 2.
Causa: a medição do tempo começava antes de importar perf_counter.

Instalação:
1. Antes de substituir, faça uma cópia do seu Intranet.py atual do GitHub.
2. Se a versão que está executando é a v2.0.5.3 entregue anteriormente, substitua o Intranet.py pelo deste ZIP.
3. Faça o commit e reinicie/recarregue o Streamlit.
4. Se houve outras alterações no seu Intranet.py após a v2.0.5.3, não sobrescreva o arquivo completo: apenas adicione `from time import perf_counter` imediatamente acima de `_INTRANET_INICIO_EXECUCAO = perf_counter()`.

Este hotfix altera somente a ordem da importação de perf_counter. Não modifique Secrets, DATABASE_URL ou tabelas.
