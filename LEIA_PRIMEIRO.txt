INTRANET STANG — ÍCONES 3D EM TODAS AS ÁREAS — v2.0.5.6

CORREÇÃO
A versão 2.0.5.5 ocultava os emojis do st.radio, mas os ícones dependiam
exclusivamente de CSS seletor frágil. Nesta versão as imagens são colocadas
nos rótulos nativos Markdown do Streamlit (st.radio e st.tabs). Os títulos
são renderizados com HTML simples <img> e imagens embutidas.

ARQUIVOS A ENVIAR À RAIZ DO GITHUB (branch main do repositório de teste):
- Intranet.py
- menu_icones_3d.py
- mod_rh.py
- mod_ferramentaria.py
- mod_fm_biblioteca.py
- mod_filiais_backup.py

Todos os arquivos foram obtidos da versão atual do repositório de teste.
NÃO envie a pasta __pycache__, PDFs, bancos CSV, credenciais ou arquivos .bak.

ORDEM RECOMENDADA
1. Gere backup pelo sistema e reserve uma cópia do código atual.
2. No repositório Intranetstangteste, use Add file > Upload files.
3. Envie os 6 arquivos e confira os nomes; confirme Commit changes.
4. Reboot app pelo Streamlit Cloud, atualize com Ctrl+Shift+R.
5. Verifique MENU LATERAL e cabeçalhos/abas de O.S., Compras, Formulários,
   Dashboard, Assinaturas, Ferramentaria, RH, Filiais/Backup.

SEGURANÇA/COMPATIBILIDADE
A seleção do st.radio e os identificadores de permissão ficam idênticos.
Não há mudança de SQL/Supabase, senhas, contas, backup, anexos, cálculos, etc.
As imagens WebP de 88x88 estão embutidas em menu_icones_3d.py.
Se faltar o módulo de ícones, o código mantém títulos e opções visíveis.

NOTA
O funcionamento com o navegador e a versão de Streamlit no Cloud ainda
precisa de validação. Se uma imagem Markdown for bloqueada, os textos
continuam funcionando; envie a captura para análise do renderer.
