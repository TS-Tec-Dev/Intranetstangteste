INTRANET STANG — ÍCONES 3D DO MENU (v2.0.5.5)
================================================

OBJETIVO
Trocar apenas os EMOJIS VISÍVEIS dos 10 itens da barra lateral por ícones 3D em WebP otimizados, mantendo intactos os identificadores internos dos menus, as permissões dos usuários e os temas claro/escuro.

INSTALAÇÃO NO GITHUB (REPOSITÓRIO Intranetstangteste)
1. Faça uma cópia do seu Intranet.py atual.
2. Abra o arquivo ZIP e extraia os dois arquivos PYTHON da raiz:
   - Intranet.py
   - menu_icones_3d.py
3. No GitHub, branch main > Add file > Upload files, envie esses DOIS arquivos à raiz.
4. Confirme a substituição em Commit changes.
5. Aguarde/reinicie o Streamlit, atualize o navegador e confira as 10 opções do menu.

A PASTA icones_3d/ NO ZIP É OPCIONAL; contém fontes PNG e WebP para edição futura.
Não é preciso fazer upload dessa pasta — os ícones já estão embutidos no menu_icones_3d.py.

SEGURANÇA / COMPATIBILIDADE
- O código foi preparado a partir do Intranet.py da branch main (blob SHA 59ce463aa16304dbacb17be760ef5398eae4542c) do repositório de teste.
- Se o Intranet.py mudou DEPOIS dessa versão, NÃO substitua por esta cópia integral: aplique o patch APENAS_MENU_3D.patch ou compare as diferenças.
- Se menu_icones_3d.py estiver ausente, a Intranet exibe os emojis anteriores em vez de travar.
- Não é necessário mudar DATABASE_URL, Supabase, secrets, usuários, assinaturas ou backups.
- A renderização usa data-URI WebP pequena, sem solicitações extras ao servidor.
- A aparência depende do DOM do Streamlit. Se uma atualização maior do Streamlit modificar a marcação do st.radio, os nomes dos menus continuarão funcionando; o CSS poderá precisar de ajuste.

ROLLBACK
Reponha o Intranet.py anterior e, se desejar, apague menu_icones_3d.py.
